# Paper Executor Agent

## Назначение
Строго **виртуальный** портфель для тренировки: открытие/закрытие бумажных
позиций по текущей рыночной цене Binance и учёт виртуального баланса. Ничему не
советует, ничего реального не исполняет.

## Только paper
Никаких реальных ордеров и никаких ключей биржи. Всё виртуальное. Цена входа и
выхода берётся из публичного тикера Binance (без ключей), но сделки — бумажные.

## Хранилище
SQLite `data/journal.db` (`data/` в `.gitignore`):
- `paper_balance(user_id, balance_usdt, updated_at)` — старт 10 000 виртуальных USDT;
- `paper_positions(id, user_id, symbol, side, entry_price, qty, stop, take,
  status open/closed, opened_at, closed_at, pnl_usdt)`.
Всё фильтруется по `user_id` — портфели пользователей изолированы.

## Логика
- Плечо **1x**: номинал позиции `qty·цена` резервируется из свободного баланса;
  на одну сделку нельзя задействовать больше свободного баланса (честное
  ограничение).
- Лонг: PnL = `(выход − вход)·qty`; шорт — зеркально `(вход − выход)·qty`.
  При закрытии баланс возвращается плюс PnL (итоговое влияние на баланс = PnL).
- Стоп/тейк опциональны. Если заданы, фоновый Сторож закрывает позицию при
  касании уровня (лонг: стоп по цене ≤ стоп, тейк по цене ≥ тейк; шорт — зеркально).

## Интерфейс
- `get_balance(user_id) -> float`
- `portfolio(user_id) -> {balance, positions}`
- `open_position(user_id, symbol, side, qty, price, stop=None, take=None) -> dict`
- `close_position(user_id, position_id, exit_price) -> {pnl_usdt, pnl_pct, ...}`
- `reset(user_id) -> 10000.0`
- `run_paper_check(fetcher=None) -> list[события автозакрытия]`
- `set_db_path(path)` — для тестов.

Цена для команд берётся из `get_ticker_24h`. Ядро (`open_position`/`close_position`)
принимает цену явно — поэтому логика тестируется на мок-ценах без сети.

## Правила
- Каждое сообщение с балансом помечается: «🧪 Виртуальный портфель. Не финансовый совет.»
- Нигде не упоминать реальные ордера или ключи API — только paper.
- Нейтральные формулировки, без рекомендаций «покупай/продавай/сигнал».
