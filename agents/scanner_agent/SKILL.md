# Scanner Agent

## Назначение
Быстрый обзор рынка: проходит по топовым USDT-парам и отмечает **ситуации**,
которые стоит посмотреть глазами (перекупленность/перепроданность, сильное
движение за сутки, всплеск объёма и т.п.).

## Честные ограничения
Сканер **находит ситуации, а не предсказывает** будущее. Он лишь считает
индикаторы на текущих данных и подсвечивает совпадения с простыми, заранее
описанными паттернами. Никаких рекомендаций «покупать/продавать» — только факты.

## Метод
1. Вселенная — топ-N USDT-пар Binance по объёму за 24ч (из 24h-тикера, без ключей).
   Исключаются стейблкоин-пары и leveraged-токены (UP/DOWN/BULL/BEAR).
2. Для каждой пары (таймфрейм 1h по умолчанию, ~200 свеч):
   - RSI 14;
   - положение цены относительно EMA 200;
   - изменение за 24ч (из тикера);
   - всплеск объёма: последний объём против среднего за 20 свеч.
3. Паттерны (может сработать несколько на пару):
   - «перепродан RSI<30»;
   - «перекуплен RSI>70»;
   - «рост 24ч >8%»;
   - «падение 24ч >8%»;
   - «всплеск объёма x2+»;
   - «выше EMA200, RSI растёт».

## Интерфейс
```
scan(timeframe='1h', top_n=30) -> list[dict]
```
Асинхронная. Возвращает список находок (пары, у которых сработал хотя бы один
паттерн), отсортированный по числу паттернов. Список может быть пустым — это
нормально, значит ярких ситуаций нет.

## Бюджет времени и данные
- Ориентир ~60–90 сек на проход; используется кэш Data Agent (TTL 60с), есть мягкий
  дедлайн — при его превышении обход прекращается на уже собранном.
- Сбой по отдельной паре не ломает весь скан (пара пропускается).
- Данные только реальные (Data Agent). API недоступен — честная ошибка, ничего не выдумывается.
