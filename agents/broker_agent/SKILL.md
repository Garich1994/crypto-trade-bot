# Broker Agent (исполнение ордеров)

## Назначение
Исполнение спот-**маркет**-ордеров в трёх режимах: `paper` → `testnet` → `live`.
Полной автоторговли нет: live-ордер уходит только после риск-гейта и подтверждения
человеком. Лимитные ордера — следующим шагом.

## Режимы (BROKER_MODE в .env, по умолчанию paper)
- **paper** — виртуальный портфель (без изменений), деньги не настоящие.
- **testnet** — Binance Spot Testnet (`testnet.binance.vision`): настоящие
  подписанные REST-вызовы, но деньги фейковые. Ключи — тестовые, из `.env`.
- **live** — реальная биржа. **Выключен по умолчанию**; включается только явной
  строкой `BROKER_MODE=live` в `.env`. Командой переключить в live нельзя.
  Базовый URL биржи настраивается (`BROKER_BASE_URL`) — для Binance.US/другой биржи.

## Безопасность (железно)
- **Ключи только из окружения** (`BINANCE_API_KEY`, `BINANCE_API_SECRET`). Нигде в
  коде не хранятся, не логируются, не печатаются, не попадают в чат/отчёты/git.
- **Каждый live-ордер**: риск-гейт PASS (стоп обязателен, корректная сторона стопа,
  R:R ≥ 1.5) **и** подтверждение тапом inline-кнопки «Подтвердить». Без тапа ордер
  не уходит.
- **Дневной лимит убытка** (`BROKER_MAX_DAILY_LOSS_USDT`): при превышении live
  блокируется до следующего дня.
- **killswitch** (`/killswitch`): мгновенно блокирует live и testnet. Разблокировка —
  вручную в `.env` (`BROKER_KILLSWITCH_RESET=1` и перезапуск).
- Все исполненные ордера пишутся в журнал с пометкой `testnet`/`live`.

## Интерфейс
- `current_mode()`, `set_mode(mode)` (paper/testnet; live — только env), `status()`.
- `place_order(user_id, symbol, side, qty, stop=None, take=None)` →
  `{status: executed|needs_confirmation|blocked, ...}`.
- `confirm_order(user_id, token)` — исполнить подтверждённый live-ордер.
- `engage_killswitch()`, `is_killed()`, `reset_killswitch_if_env()`.
- `_sign(query, secret)` — HMAC SHA256 подпись (ключи из env).

## Правила
- Ключи — только чтение из env; в отчётах лишь факт «ключи не в коде».
- Тексты на русском; перед кнопкой подтверждения — «ВНИМАНИЕ: реальный ордер».
