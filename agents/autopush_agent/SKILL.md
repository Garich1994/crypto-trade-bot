# Autopush Agent (Signal Watcher)

## Назначение
Автономный фоновый пуш **сильных наблюдений**. По кругу прогоняет
`coordinator.build_brief()` и шлёт пользователю только то, что прошло жёсткий порог.
Это наблюдения, а не рекомендации. По умолчанию **выключен** — включает пользователь.

## Порог пуша
Идея пушится, если одновременно:
- **сила сетапа ≥ 75** (score из сканера);
- **риск-гейт PASS** — идея осталась в `brief['ideas']` (FAIL ушли в `filtered_out`);
- **скептик без FAIL** — все проверки скептика пройдены (`skeptic_passed == skeptic_total`).

## Антиспам
- одна пара+сторона — **не чаще раза в 12 часов** (таблица `push_log`, фильтр по `user_id`);
- **максимум 5 пушей в сутки** на пользователя (скользящие 24ч);
- **тихий час 00:00–07:00 America/New_York** — ночью не пушим.

## Формат пуша
```
🔔 BTCUSDT · лонг
Сила сетапа 82/100 — Тренд, Объём
Вход 67 400, стоп 65 258, тейк 70 618
Скептик: пройдено 5/5
Наблюдение, не рекомендация. Не финансовый совет.
```

## Фоновый цикл
Отдельная asyncio-задача в `bot.main` (как автодайджест), интервал настраиваемый
(по умолчанию **2 часа**). Работает только пока запущен процесс бота.
Хранилище — `data/journal.db` (таблицы `push_subs`, `push_log`).

## Команды
`/autopush on [часы]` — включить, `/autopush off` — выключить, `/autopush status` —
статус. По умолчанию выключено.

## Интерфейс
- `set_autopush(user_id, active, interval_h=2)`, `get_autopush(user_id)`;
- `due_subscriptions(now)`, `mark_sent(user_id, now)`;
- `evaluate_push(brief, user_id, now)` — чистый отбор пушей (тестируется на мок-брифе);
- `run_push_cycle(builder=None, now=None)` — цикл по подписчикам;
- `set_db_path(path)` — для тестов.
