# Risk Manager Agent

## Назначение
Проверка параметров риска на соответствие классическим лимитам. Это
**предупреждение, а не запрет**: бот ничего не блокирует и ничем не управляет, он
лишь подсвечивает, где риск выглядит повышенным, и оставляет решение человеку.

## Правила
- Риск на сделку **> 2%** → предупреждение «выше классического лимита».
- Суммарный риск = `risk_pct * (open_trades + 1)`. Если он **> max_total_risk_pct**
  (по умолчанию 6%) → предупреждение «превышен лимит суммарного риска».
- Если обе проверки в норме → «в пределах лимитов».

## Интерфейс
```
check_risk(deposit_usdt, risk_pct, open_trades=0, max_total_risk_pct=6)
    -> {"per_trade_ok", "total_risk_pct", "verdict", "advice"}
```
- `per_trade_ok` — bool (риск на сделку ≤ 2%).
- `total_risk_pct` — суммарный риск с учётом новой сделки, %.
- `verdict` — короткий итог.
- `advice` — одна строка нейтрального совета.

Синхронная (чистая арифметика). Валидация: `deposit_usdt > 0`, `risk_pct ∈ (0, 100]`,
`open_trades ≥ 0`, `max_total_risk_pct > 0` — иначе `RiskError`.
