# Exit Planner Agent

## Назначение
Расчёт уровней выхода (стоп и два тейка) от заданной цены входа — как арифметика
по ATR и ближайшим уровням, а не рекомендация. Агент не советует входить или
выходить, он лишь считает, где оказались бы уровни при заданных параметрах.

## Логика
1. Берётся ATR(14) на текущем таймфрейме.
2. Начальный стоп: `entry ∓ atr_mult * ATR` (для long — ниже, для short — выше);
   по умолчанию `atr_mult = 1.5`. Риск = |entry − stop|.
3. Начальные тейки от риска: тейк1 = R:R 1:1.5, тейк2 = R:R 1:2.
4. **Подтяжка к уровням S/R**: если рядом (в пределах 0.75·ATR) есть свинговый
   уровень, уровень округляется к нему — стоп к ближайшей поддержке/сопротивлению
   со «своей» стороны, тейки к ближайшему сопротивлению (long) / поддержке (short).
   Подтяжка применяется только если не ломает порядок `stop < entry < take1 < take2`
   (для short — зеркально).
5. Возвращаются итоговые уровни и **фактический** R:R (после подтяжки).

## Интерфейс
```
plan_exit(symbol, timeframe, side, entry_price, atr_mult=1.5)
    -> {"stop", "take1", "take2", "rr1", "rr2", ...}
```
Дополнительно в ответе: `atr`, `atr_mult`, `risk`, `snapped` (какие уровни
подтянулись к S/R). Асинхронная.

## Ошибки и данные
- `side` ∈ {long, short}; `entry_price` > 0 — иначе понятная ошибка (`ExitError`).
- Данные только реальные (Data Agent). API недоступен — честная ошибка, без выдумок.
- Комиссии и проскальзывание не моделируются (честное упрощение).
