# Entry Timer Agent

## Назначение
**Оценка условий входа** по заданной стороне (long/short). Это не призыв входить и
не рекомендация. Агент считает набор факторов на текущих данных и сводит их в один
балл 0–100, где выше = условия для рассматриваемого входа выглядят благоприятнее.

## Честное ограничение
Скоринг описывает **прошлое и настоящее** (индикаторы на имеющихся свечах).
Будущего он не знает и не предсказывает. Балл — это удобная сводка условий, а не
вероятность успеха.

## Факторы и веса
Старт — 50 баллов (нейтрально). Каждый фактор добавляет/снимает до половины своего
веса, суммарный размах ±50 → итог в [0, 100].

| Фактор                         | Вес | Как влияет (для long; для short — зеркально)        |
|--------------------------------|-----|------------------------------------------------------|
| RSI 14                         | 20  | перепроданность — в плюс, перекупленность — в минус  |
| MACD (направление)             | 15  | импульс в сторону входа — в плюс                     |
| Цена vs EMA 20/50/200          | 20  | чем больше EMA «под ценой» (для long) — тем плюсовее |
| Положение между S/R            | 15  | ближе к поддержке (для long) — в плюс, к сопротивлению — в минус |
| Волатильность ATR 14           | 15  | высокая волатильность — в минус (хуже для входа), для любой стороны |
| Объём vs средний (20)          | 15  | участие объёма — в плюс, «тонкий» рынок — в минус     |

Веса подобраны эвристически и namеренно простые/прозрачные.

## Интерфейс
```
score_entry(symbol, timeframe, side) -> {"score": int, "factors": [...], "summary": str}
```
Асинхронная. `factors` — список `{"label": str, "points": int}` (знак = вклад).
`summary` — 1–2 нейтральных предложения, без слов «входи/покупай/продавай/сигнал».

## Ошибки и данные
- `side` ∈ {long, short}, иначе понятная ошибка (`EntryError`).
- Данные только реальные (Data Agent). API недоступен — честная ошибка, без выдумок.
