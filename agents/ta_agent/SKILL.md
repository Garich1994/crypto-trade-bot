# TA Agent

## Назначение
Технический анализ пары по данным от Data Agent. Считает индикаторы и описывает
состояние рынка **нейтрально**. Никаких рекомендаций «покупать/продавать» —
агент не даёт торговых указаний, только факты о цене и индикаторах.

## Индикаторы
- **EMA 20 / 50 / 200** — скользящие средние, оценка тренда.
- **RSI 14** — с состоянием: перекупленность (>70), перепроданность (<30), нейтрально.
- **MACD (12, 26, 9)** — линия MACD, усреднённая линия, гистограмма (описываются нейтрально).
- **ATR 14** — волатильность (абсолютная и в % от цены).
- **Bollinger Bands (20, 2)** — верхняя/средняя/нижняя полосы.
- **Уровни поддержки/сопротивления** — по свингам (локальным экстремумам).
- **Анализ объёма** — последний объём относительно среднего.

## Главная функция
```
analyze(symbol, timeframe) -> dict
```
Асинхронная. Возвращает словарь с полями:
`symbol, timeframe, price, change_24h, trend, rsi, rsi_state, macd_state,
atr, atr_pct, volatility_state, support, resistance, bollinger, volume_state,
funding_rate`.

При недоступности API или неизвестном тикере пробрасывает `DataAgentError`
(текст показывается пользователю без трейсбека).

## Правило формулировок
В коде и в текстах **запрещены** слова «покупай», «продавай», «сигнал».
Допустимы только нейтральные описания состояния, например «RSI в зоне
перекупленности», «MACD выше усреднённой линии». Решение всегда за человеком.
