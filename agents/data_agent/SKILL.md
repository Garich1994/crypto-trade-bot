# Data Agent

## Назначение
Единая точка сбора рыночных данных для остальных агентов. Отдаёт сырые данные
(свечи, тикер, funding rate) в удобном виде. Ничего не интерпретирует — анализ
делает TA Agent.

## Источники данных
Публичный API Binance, **без API-ключей** (только публичные эндпоинты, read-only):

| Данные            | Эндпоинт                                        | Рынок        |
|-------------------|-------------------------------------------------|--------------|
| Свечи (OHLCV)     | `GET api.binance.com/api/v3/klines`             | спот         |
| 24h тикер         | `GET api.binance.com/api/v3/ticker/24hr`        | спот         |
| Funding rate      | `GET fapi.binance.com/fapi/v1/premiumIndex`     | фьючерсы USDT-M |

Поддерживаемые таймфреймы свечей: `15m`, `1h`, `4h`, `1d`.

## Лимиты и правила
- Лимит Binance ~1200 запросов/мин на IP. Чтобы не долбить API, ответы кэшируются
  **в памяти с TTL 60 секунд** (ключ — эндпоинт + параметры).
- Таймаут запроса берётся из `core.config.HTTP_TIMEOUT` (по умолчанию 10 с).
- При сетевой ошибке/таймауте делается **1 повтор**, затем наружу летит понятное
  исключение `DataAgentError` (без трейсбека для пользователя).
- API-ключи не используются и не требуются. Данные не выдумываются: если источник
  недоступен — возвращается честная ошибка.
- Funding rate есть не у всех пар (нужны фьючерсы USDT-M). Если его нет — возвращается
  `None`, это не ошибка.

## Публичный интерфейс
- `get_klines(symbol, interval, limit=300) -> list[list]`
- `get_ticker_24h(symbol) -> dict`
- `get_funding_rate(symbol) -> float | None`  (в долях, напр. 0.0001 = 0.01%)

Все функции асинхронные (`async def`).
