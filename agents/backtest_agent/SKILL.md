# Backtest Agent

## Назначение
«Машина времени»: прогоняет заданные уровни сделки (вход / стоп / тейк) по
**исторической** цене и считает, как такая схема вела бы себя в прошлом.

## Честно о методе
Это **исторический replay, а не предсказание будущего**. Агент не угадывает, куда
пойдёт цена. Он лишь воспроизводит прошлые свечи и механически проверяет, что
случилось бы с конкретными уровнями. Прошлое не гарантирует будущего. Никаких
рекомендаций «покупать/продавать» — только статистика.

## Логика (прозрачная, без магии)
1. Скачиваются исторические свечи (до `max_candles`, по умолчанию 5000).
2. Идём по истории от старых свечей к новым.
3. Сделка **открывается**, когда свеча касается цены входа:
   `low <= entry <= high` (для лонга; для шорта условие то же — цена прошла уровень).
4. Дальше идём вперёд, пока не задет **стоп** или **тейк** (по `high`/`low` свечи):
   - лонг: `low <= stop` → убыток; `high >= take` → профит;
   - шорт: `high >= stop` → убыток; `low <= take` → профит;
   - если в одной свече задеты оба уровня — консервативно считаем, что первым сработал стоп.
5. Если за **100 свечей** не задет ни стоп, ни тейк — закрытие по рынку (по `close`).
6. После закрытия позиция может открыться снова при следующем касании входа.

## Метрики
Число сделок, win rate, средний R, expectancy (ожидаемый R на сделку),
profit factor (валовый профит / валовый убыток), максимальная просадка (в R).
R считается как `(выход − вход) * направление / |вход − стоп|`.

## Валидация
- `side` ∈ {long, short}.
- Лонг: `stop < entry < take`. Шорт: `take < entry < stop`. Иначе — понятная ошибка на русском.
- Если в истории не было ни одного касания входа — понятная ошибка (не трейсбек).

## Ограничения
- Не более ~30 сек на расчёт; `max_candles=5000` по умолчанию (чистый проход по свечам — доли секунды).
- Комиссии и проскальзывание не моделируются (упрощение, честно обозначено).
- Данные берутся у Data Agent. API недоступен → честная ошибка, ничего не выдумывается.

## Интерфейс
```
backtest(symbol, timeframe, side, entry_price, stop_price, take_price, max_candles=5000) -> dict
```
Асинхронная функция.
