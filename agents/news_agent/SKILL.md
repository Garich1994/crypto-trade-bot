# News Monitor Agent

## Назначение
Короткая лента свежих крипто-новостей, чтобы быстро увидеть заголовки и перейти
к первоисточнику. Агент ничего не комментирует и не оценивает — только собирает
заголовки.

## Источники (без ключей)
RSS-ленты публичных изданий, парсинг через `feedparser`:
- CoinDesk;
- Cointelegraph.

Берутся последние ~15 записей из каждой ленты, оставляются только **свежее 24ч**,
результаты объединяются и сортируются по времени (новые сверху).

## Интерфейс
```
get_crypto_news(limit=5) -> list[dict]
```
Асинхронная. Каждый элемент: `{title, source, time, url}`, где `time` —
timezone-aware `datetime` (UTC).

## Правила
- Данные не выдумываются: если RSS недоступен, запись просто не появляется.
- Сбой одной ленты не ломает другую (она пропускается).
- Если доступных свежих новостей нет — возвращается пустой список; вежливое
  сообщение об этом показывает Telegram-слой (а не придуманные новости).
- Сетевые запросы с таймаутом; парсинг вынесен в поток, чтобы не блокировать loop.
