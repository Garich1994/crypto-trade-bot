# Skeptic Agent (критик сделок)

## Назначение
Проверяет идею сделки на прочность по набору простых правил и показывает **слабые
места**. Rule-based, без LLM. Не выносит вердикт «входить или нет» — только факты
проверок: слабые места найдены или не найдены.

## Вход
`symbol, side (long/short), entry, stop, take`.

## Проверки (каждая PASS/FAIL с цифрами)
1. **RSI против направления**: лонг при RSI > 70 — FAIL (перекупленность против
   лонга); шорт при RSI < 30 — FAIL; иначе PASS.
2. **Стоп vs волатильность**: дистанция до стопа `|entry − stop|`. Меньше 1.0×ATR —
   FAIL («стоп уже ATR, выбьет шумом»); иначе PASS (≥1.5×ATR — уверенный PASS).
3. **Уровни против**: ближайший S/R в сторону цели ближе, чем тейк — FAIL с цифрой
   («сопротивление 80 388 ближе тейка 81 200»); иначе PASS.
4. **Участие объёма**: объём < 0.7× среднего (20 свеч) — FAIL («движение на слабом
   участии»); иначе PASS.
5. **Тренд против**: цена с «неправильной» стороны EMA200 для направления — FAIL.

## Интерфейс
- `skeptic(symbol, side, entry, stop, take) -> dict` (fetch + анализ);
- `analyze_idea(side, entry, stop, take, metrics) -> dict` — чистая функция
  (тестируется на мок-данных без сети); `metrics` = `price, rsi, atr, ema200,
  volume_ratio, support, resistance`.

Результат: `checks` (список `{name, status, detail}`), `passed`, `total`,
`weak_points`, `summary`.

## Правила
- Нейтральные формулировки, без «входи/не входи» — только факты проверок и итог
  вида «Прошла 4/5» или «Слабых мест не найдено (5/5)».
- Данные только реальные (Data Agent). API недоступен — честная ошибка.
