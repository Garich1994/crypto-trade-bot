# Whale Tracker Agent

## Назначение
Подсветка крупных («китовых») сделок на **споте** Binance за недавнее окно: сколько
их было, давление покупок/продаж и топ крупнейших сделок. Это необычная активность
как **факт прошлого** — не рекомендация и не прогноз.

## Честные оговорки
- Китовые сделки — **факт прошлого, а не повод для сделки**. Это причина посмотреть
  на график, а не указание действовать. Никакого «кит купил — повторяй».
- Ликвидации фьючерсов из региона недоступны (Binance Futures отвечает 451).
  Доступен только спот. Данные не выдумываются.

## Источник
Публичный эндпоинт `aggTrades` (`/api/v3/aggTrades`), без ключей. Поля: цена `p`,
объём `q`, время `T`, флаг `m` (buyer is maker). Notional = `p·q`.

### Как читается флаг `m`
- `m == false` — покупатель был тейкером → **агрессивная покупка** (buy);
- `m == true` — покупатель был мейкером → **агрессивная продажа** (sell).

## «Кит»
Сделка с notional ≥ порога. По умолчанию: BTC — ≥ 250 000 USDT, остальные —
≥ 100 000 USDT. Порог настраивается параметром.

## Давление
Среди китовых сделок сравнивается суммарный notional покупок и продаж:
покупки заметно больше → «покупки», продажи больше → «продажи», иначе «смешанное».

## Интерфейс
- `get_whales(symbol, threshold=None, window_min=15) -> dict` (fetch + анализ);
- `analyze_whales(trades, symbol, threshold=None, window_min=15, now_ms=None) -> dict`
  (чистая функция — тестируется на мок-сделках без сети);
- `default_threshold(symbol) -> float`;
- `LIQUIDATIONS_NOTE` — честная заглушка про недоступность ликвидаций.

Результат: `whale_count, buy_notional, sell_notional, pressure, window_minutes,
top[]` (топ-3 крупнейших: цена, объём, notional, сторона, время).

## Кэширование и лимиты
Данные идут через Data Agent с кэшем TTL 60с — не чаще 1 запроса в 60с на пару.

## Методология
Идея «необычная активность + контекст» адаптирована (прочитана, не установлена) из
day-trader-skill (trader-pelosi): крупную активность показываем как публичный факт
прошлого с оговоркой, что это повод посмотреть, а не готовая сделка; без
акций-специфики и без обещаний доходности.

## Правила
- Только факты и давление, без торговых рекомендаций.
- Нет данных — честная ошибка, ничего не выдумывать.
