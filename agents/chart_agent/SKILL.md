# Chart Agent

## Назначение
Рисует PNG-графики в тёмной премиальной теме (ориентир — Binance dark) через
matplotlib. Только визуализация цены и индикаторов — никаких подписей-рекомендаций.

## Что на графике
- Свечи: зелёные (#0ecb81) рост / красные (#f6465d) падение (фитили + тела).
- EMA 20 (жёлтая #f0b90b) и EMA 50 (серая #848e9c) на панели цены.
- Панель объёма барами снизу (цвет по направлению свечи).
- Отдельная панель RSI 14 с зонами 30/70 (пунктир).
- Тёмный фон (#0b0e11), приглушённая сетка, подпись пары и таймфрейма.
- Размер ~1200×700, dpi 100. Backend Agg (без GUI).

## Функции
- `plot_analysis(symbol, timeframe="1h") -> path` — скачивает свечи и рисует.
- `plot_backtest(symbol, entry, stop, take, timeframe="1h") -> path` — тот же график
  плюс горизонтальные линии: вход (белая), стоп (красная), тейк(и) (зелёные).
- `render_analysis(symbol, timeframe, rows)` / `render_backtest(...)` — чистый рендер
  по готовым свечам (тестируется на мок-данных без сети).

Функции возвращают путь к временному PNG; **файл удаляет вызывающая сторона**
после отправки.

## Правила
- На графике нет подписей «покупай/продавай» — только цена, индикаторы и линии
  уровней. Статические подписи перечислены в `CHART_LABELS` (все нейтральные).
- Данные только реальные (Data Agent). API недоступен — ошибка пробрасывается.
