# Деплой crypto-trade-bot на VPS (Docker + HTTPS)

Пошагово для человека. В итоге бот работает 24/7, а дашборд открывается по HTTPS
(и может подключаться как Telegram Mini App). Секреты — только в `.env` на сервере,
в git они не попадают.

## Что получится
- Контейнер `bot` — Telegram-бот (long polling) + веб-дашборд на порту 8080 (внутренний).
- Контейнер `caddy` — обратный прокси с авто-HTTPS (Let's Encrypt) на ваш домен.

---

## Шаг 1. Арендовать VPS
- Подойдёт недорогой сервер, например **Hetzner CX22** (~€4.15/мес) или аналог
  (Timeweb, Aeza, DigitalOcean и т.п.).
- ОС: **Ubuntu 24.04**.
- После создания у вас есть **IP-адрес** сервера и доступ по SSH.

Установите Docker (на свежей Ubuntu):
```
curl -fsSL https://get.docker.com | sh
```

## Шаг 2. Направить домен на сервер
- В DNS вашего домена создайте **A-запись** для поддомена на IP сервера.
  Пример: `pilot.soario.ai` → `203.0.113.10`.
- Подождите, пока запись распространится (обычно минуты, иногда до часа).

## Шаг 3. Запустить на сервере
```
git clone <URL-репозитория> crypto-trade-bot
cd crypto-trade-bot
cp .env.example .env
nano .env            # впишите BOT_TOKEN и DOMAIN (тот самый поддомен)
docker compose up -d --build
```
Caddy сам получит HTTPS-сертификат для вашего `DOMAIN` при первом запросе.

## Шаг 4. Проверить
- Живость: откройте `https://DOMAIN/healthz` — должно вернуться `{"ok": true}`.
- Дашборд: откройте `https://DOMAIN/` в браузере.
- Из Telegram: команда `/dashboard` пришлёт кнопку с вашим адресом.

## Шаг 5. Логи и обслуживание
```
docker compose logs -f           # смотреть логи в реальном времени
docker compose logs -f bot       # только бот
docker compose restart bot       # перезапустить бота
docker compose pull && docker compose up -d --build   # обновить после git pull
```

---

## Важное
- **Секреты только в `.env` на сервере.** В репозитории лежит лишь `.env.example`.
- База данных (`data/journal.db`) хранится в томе `./data` на сервере и переживает
  пересборку контейнера.
- Порты наружу открывает только Caddy (80/443). Бот/дашборд доступен снаружи
  исключительно через HTTPS.
- ⚠️ Это аналитический инструмент, не финансовый совет.
